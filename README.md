# Site de Extensão Universitária - UFRRJ

## 📋 Sobre o Projeto
Este projeto consiste no desenvolvimento de um site institucional para a Universidade Federal Rural do Rio de Janeiro (UFRRJ), com foco na divulgação e organização das atividades de extensão universitária.

O site foi desenvolvido tentando seguir a identidade visual da UFRRJ, garantindo conformidade com os padrões institucionais de marca, cores e tipografia.

No entanto, é necessária avisar que, inicialmente este projeto é resultado de um trabalho para conclusão da matéria de Introdução a Sistemas Web.
